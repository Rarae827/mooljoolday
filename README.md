# MooljoolDay · 물줄때 리듬게임

> 목마르면, 물방울이 쏙.

스마트 화분 **MooljoolDay**의 캐릭터 *땀땀이*가 떨어지는 물방울을 받아 먹는 웹 리듬게임입니다.
5개 라인을 따라 음악에 맞춰 내려오는 물방울을 좌우로 움직여 받고, 3번 놓치면 식물이 시들어요.

## 플레이 방법
- **모바일 / 태블릿:** 화면을 좌우로 드래그
- **PC:** `D` `F` `G·H` `J` `K` 키로 줄 선택 (방향키·마우스도 가능), `ESC` 일시정지
- 곡을 끝까지 완주하면 화분에 꽃이나 방울토마토가 열리고 **식물 도감**에 등록돼요.
- 완곡 후에는 x1.2 → x1.5 → … 로 빨라지며 계속 이어집니다.

## 폴더 구조
```
web/   플레이어용 게임 (GitHub Pages로 배포되는 폴더)
dev/   개발자 전용 확인 페이지 (배포되지 않음)
```

## 로컬에서 실행
```bash
python -m http.server 5173 --directory web   # 게임: http://localhost:5173
python -m http.server 5174                   # 개발용: http://localhost:5174/dev/plants.html
```
자동 테스트 시에는 `?mute`를 붙이면 소리가 나지 않아요. 예) `http://localhost:5173/?mute`

## 음악
- **MooljoolDay 테마곡:** 오리지널 곡
- **그 외 곡:** 저작권이 만료된 클래식·민요·동요 멜로디를 직접 입력하고 반주를 자동 편곡했어요.
- 모든 소리는 음원 파일 없이 Web Audio로 실시간 합성돼요.
